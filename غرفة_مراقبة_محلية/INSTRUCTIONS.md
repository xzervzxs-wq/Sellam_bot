# تعليمات التشغيل - نظام المراقبة المحلي

## 🚀 بدء التشغيل السريع

### الطريقة الأولى: النسخة الكاملة
```
افتح ملف: index.html
كود الدخول: 1234
```

### الطريقة الثانية: النسخة المدمجة  
```
افتح ملف: standalone.html
(لا يتطلب ملفات خارجية)
```

## 📁 هيكل الملفات

```
غرفة_مراقبة_محلية/
├── index.html              # التطبيق الرئيسي
├── standalone.html         # النسخة المدمجة
├── data-manager.js         # مدير البيانات
├── README.md              # الوثائق الرئيسية
├── INSTRUCTIONS.md        # هذا الملف
└── data/                  # مجلد البيانات
    ├── screens.json           # 🖥️ شاشات العرض والكاميرات
    ├── users.json             # 👥 المستخدمين وأكواد الدخول
    ├── activity_log.json      # 📋 سجل الأنشطة
    ├── external_departments.json # 🏢 الأقسام الخارجية
    ├── policies.json          # 📑 السياسات والملفات
    ├── incidents.json         # ⚠️ الحوادث والتقارير
    ├── maintenance.json       # 🔧 الصيانة والإصلاحات
    └── settings.json          # ⚙️ إعدادات النظام
```

## 🛠️ المميزات والوظائف

### للمدير (Admin):
- ✅ عرض جميع الشاشات والكاميرات
- ✅ إدارة المستخدمين وإضافة أكواد جديدة
- ✅ إدارة الأقسام الخارجية
- ✅ رفع وإدارة ملفات السياسات
- ✅ عرض سجل الأنشطة الكامل
- ✅ إعدادات النظام والنسخ الاحتياطي
- ✅ إعادة تعيين البيانات

### للمشاهد (Viewer):
- ✅ عرض الشاشات والكاميرات
- ✅ عرض سجل الأنشطة
- ❌ لا يمكن تعديل الإعدادات
- ❌ لا يمكن إضافة مستخدمين

## 💾 إدارة البيانات

### الحفظ التلقائي:
- يتم حفظ جميع التعديلات تلقائياً
- البيانات محفوظة في localStorage
- نسخة احتياطية في ملفات JSON

### النسخ الاحتياطي:
```javascript
// تصدير البيانات
استخدم زر "تصدير البيانات" في لوحة التحكم

// استيراد البيانات  
استخدم زر "استيراد البيانات" واختر ملف JSON
```

### إعادة التعيين:
```javascript
// إعادة تعيين كاملة
استخدم زر "إعادة تعيين" في لوحة التحكم
تحذير: سيتم حذف جميع البيانات!
```

## 🔧 استكشاف الأخطاء

### المشكلة: لا يتم تحميل البيانات
```
الحل: تأكد من وجود ملفات JSON في مجلد data/
أو استخدم النسخة المدمجة standalone.html
```

### المشكلة: كود الدخول لا يعمل
```
الحل: تأكد من استخدام الأكواد الافتراضية
أو تحقق من ملف data/users.json
```

### المشكلة: البيانات لا تحفظ
```
الحل: تحقق من permissions المتصفح
أو استخدم خادم محلي للملفات
```

## 🆘 الدعم الفني

### للحصول على المساعدة:
1. راجع ملف README.md
2. تحقق من ملفات البيانات في مجلد data/
3. احفظ نسخة احتياطية قبل أي تعديل
4. تواصل مع المطور عند الحاجة

### المشاكل الشائعة والحلول:

#### لا يظهر محتوى:
```javascript
// تحقق من console في المتصفح
F12 > Console > ابحث عن أخطاء
```

#### البيانات اختفت:
```javascript  
// تحقق من localStorage
F12 > Application > Storage > Local Storage
```

#### الملفات لا تفتح:
```
جرب استخدام خادم محلي:
python -m http.server 8000
ثم افتح: http://localhost:8000
```
