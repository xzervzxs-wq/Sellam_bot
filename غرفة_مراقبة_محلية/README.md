# نظام المراقبة المحلي - غرفة المراقبة والتحكم

نسخة محلية من نظام إدارة الأمن والسلامة، تعمل بدون اتصال بالإنترنت وتحفظ البيانات محلياً.

## المحتويات

### الملفات الأساسية
- `index.html` - الملف الرئيسي للنظام
- `data/` - مجلد البيانات المحلية

### ملفات البيانات
- `data/screens.json` - بيانات شاشات العرض والكاميرات
- `data/users.json` - بيانات المستخدمين وأكواد الدخول
- `data/external_departments.json` - بيانات الأقسام الخارجية
- `data/policies.json` - ملفات السياسات المرفوعة
- `data/activity_log.json` - سجل الأنشطة والعمليات
- `data/incidents.json` - بيانات الحوادث
- `data/maintenance.json` - بيانات الصيانة
- `data/settings.json` - إعدادات النظام

## التشغيل

1. افتح الملف `index.html` في متصفح الويب
2. استخدم كود الدخول الافتراضي: `1234`
3. اسم المستخدم الافتراضي: `Admin`

## المميزات

### المميزات الجديدة في النسخة المحلية:
- ✅ تخزين البيانات محلياً في ملفات JSON منفصلة
- ✅ لا يتطلب اتصال بالإنترنت للعمل
- ✅ حفظ تلقائي للبيانات عند التعديل
- ✅ إمكانية تصدير واستيراد البيانات
- ✅ مؤشر التخزين المحلي في الواجهة
- ✅ نظام تخزين منظم في مجلد data

### المميزات الأساسية:
- إدارة شاشات العرض والكاميرات
- نظام المستخدمين (مدير / مشاهد)
- إدارة الأقسام الخارجية
- رفع وإدارة السياسات والملفات
- سجل الأنشطة والعمليات
- واجهة باللغة العربية مع دعم RTL
- تصميم مظلم حديث

## الاستخدام

### إضافة بيانات جديدة:
- يتم حفظ جميع التعديلات تلقائياً في ملفات البيانات
- بإمكانك تحرير ملفات JSON مباشرة إذا لزم الأمر

### النسخ الاحتياطي:
- استخدم زر "تصدير البيانات" لحفظ نسخة احتياطية
- استخدم زر "استيراد البيانات" لاستعادة نسخة احتياطية

### إعادة تعيين النظام:
- استخدم زر "إعادة تعيين" لحذف جميع البيانات والعودة للإعدادات الافتراضية

## الإعدادات الافتراضية

### بيانات تجريبية:
- شاشتان للعرض (A و B)
- كاميرات تجريبية في كل شاشة
- مستخدم مدير بكود 1234

### أكواد الدخول:
- المدير: 1234
- يمكن إضافة مستخدمين جدد من لوحة التحكم
